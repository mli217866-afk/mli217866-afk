## 我的产品原则

- **业务价值优先**：先明确要改善的决策和工作流程，再选择技术方案
- **证据胜过自信表达**：让结论能够追溯到原始资料
- **保留人的控制权**：重要操作应当可观察、可拦截、可审计
- **面向真实生产环境**：同时处理状态、权限、重试、恢复和部署
